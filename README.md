# Document Intelligence Platform

Decoupled FastAPI + React AI Application with LangChain, PyMuPDF, ChromaDB, and Vector Retrieval.

## 🚀 24/7 Cloud Hosting
Configured for instant 24/7 standalone container hosting on Hugging Face Spaces, Render, Railway, and Vercel.

## 🛠️ Features
- **PDF Audit & Validation**: Pre-embedding sanity checks (size, encryption, extractable text).
- **Multimodal Diagram & Vision Extraction**: PyMuPDF image extraction with OCR and OpenAI Vision descriptions.
- **Interactive Roadmap Summaries**: Visual stage-by-stage learning roadmaps with key concepts.
- **Page Citation RAG Q&A**: Fast vector retrieval returning exact source page references.
